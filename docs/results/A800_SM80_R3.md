## 轮次取舍

- **Verified · R0**　复核 Llama-1B B16、Llama-3B B16 和 OLMoE B8，保留同卡近似平局的正式配置。 [试验和回执](A800_SM80_R3_R0.md)
- **Verified · R1**　新增 321 项 guarded MMA 几何价格，registry 从 92 增至 413。全 40 格完成离线重算与重新筛选。 [试验和回执](A800_SM80_R3_R1.md)
- **Verified · R2**　Llama-3B B16 用 TN256 和 down 三槽。Llama-8B 与 Mistral B16 选择 216 CTA 的 TN224。两种 B8 模型保留 TN224。 [试验和回执](A800_SM80_R3_R2.md)
- **Verified · R3**　OLMoE B8/B16 采用 216 CTA。探针在全部 108 个 SM 观察到重叠工作。大 dense O/down 保留原三槽。 [试验和回执](A800_SM80_R3_R3.md)
- **Verified · R4**　MoE slot padding、attention mask strip 和 retile 后的 live-row epilogue 均完成对照，正式配置沿用原 body。 [试验和回执](A800_SM80_R3_R4.md)
- **Verified · R5**　补齐 activation issue 与新 KV 行价格，核对 wave tail 和跨阶段重叠。MMA 留一误差中位数为 14.902%。Qwen segments/copy8 的数值排序仍与同卡近似平局相反。共享区间仍按逐任务带宽模型计价。 [试验和回执](A800_SM80_R3_R5.md)
- **Verified · R6**　有界 L2 prefetch 在旧布局和 retile 后共享布局的两次比较均落在 0.50% 内，保留为实验选项。 [试验和回执](A800_SM80_R3_R6.md)
- **Verified · R7**　Qwen30 B16 选择复用 arena 的四槽融合专家。每任务行基址和打包 token 的对照差值落在平局内。 [试验和回执](A800_SM80_R3_R7.md)
- **Verified · R8**　保留 160 线程 role ABI。生产和校准均沿用 32 producer 与 128 consumer。 [试验和回执](A800_SM80_R3_R8.md)
