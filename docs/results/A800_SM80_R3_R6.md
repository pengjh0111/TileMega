# A800 SM80 R3 R6 · stage-entry weight prefetch

**Verified implementation.** The SM80 producer can prefetch up to 4 KiB of the next GEMM's first weight tile into L2. The option applies at the preceding producer's tail when the next GEMM has no existing pre-issue. Each active lane fetches an aligned cache-line address. The shared arena, ring phase, barrier arrivals, and consumer math follow the existing path.

**Verified comparison.** Job `351504_0` completed in 3 min 25 s. These are three independent processes on the same guarded A800, each with one warmup and three timed requests for N=1 and N=1024. The seed-0 checkpoint, prefill, prompt, and all output tokens matched the archived incumbent.

**Verified decision.** Prefetch improved the three matched TPOT repeats by 0.009755, 0.012619, and 0.009536 ms/token. The median improvement was 0.147%. The attention arm improved the median by 0.153%. Both fell inside the 0.50% tie threshold, so this comparison leaves both options disabled.
