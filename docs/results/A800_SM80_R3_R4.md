# A800 SM80 R3 R4 · activation and history padding

**Verified plan.** OLMoE B8 tests first-visit zero fill for expert activation slots, skipping wholly masked attention strips, and their combination. Keep the archived prefill mode, native coordinate, checkpoint, and prompt. Run each binary once on the same physical A800. Promote a body only after all three matched TPOT repeats improve, the median gain exceeds 0.50%, and the full outputs and workload identities agree.

**Verified implementation.** Expert rows are zeroed at the first visit to each slot of a task. Task transitions can change the row count and the activation layout. Every lane still participates in the router shuffle and publishes its arrival. Attention leaves a partially valid 16-key strip padded with zeros for the V MMA and skips full masked strips.
