## 原生执行链

`scripts/a800_solve.py` 将固定模型导出、A800 target、prefill 和 seed 交给 `tilemega compile --search pipeline --selection measure`。编译器建立 ModelPlan 和 CTG，将 task ownership 与同步边界传递到 whole-program flow，随后精化候选并 replay。候选生成 typed tmexec，编译为 SM80 cubin。链接后的寄存器、共享内存和 CUDA driver 可驻留 CTA 数参与筛选与重评分。入围候选各用一个进程跑完整请求。最终产物另作完整 HF teacher-forced 与 step/loop 正确性检查，再启动独立正式计时。

SM80 和此处的 SM90 GEMM 共用 BF16 `mma.sync` 算术。SM80 用 32 个 producer lanes 发起显式地址的 16-byte `cp.async`，用 128 个消费者完成 MMA、归约与 epilogue。full/side 以 32 个 producer arrivals 发布，empty 由 128 个消费者归还。跨 stage 继续使用独立的 ring generations 和 operand banks。实际架构和实现以生成源码、链接资源和 artifact manifest 为准。

新实验按 `a800-single-v2` 记录诊断、配对、选择、正确性和正式计时。每种测试及配置只启一个独立进程。每个计时进程保留 N1/N1024 各一次 warmup 和三次计时。A/B 两臂使用同一个 allocation，顺序执行。历史有效进程及均衡顺序实验保留实际次数。CPU 编译与分析在登录节点执行。新增求解作业启动时复核提交计划中的源码、模型导出、target、prefill、seed 和 compiler 哈希。

## 23:19 实验更新

**已测量。** 严格守护接受 `347253` 的 9 个完整 dense gate body 进程。探针使用生产 160-thread 角色分工、`cp.async`、MMA 和 epilogue。插桩前后输出逐位相同。Llama-1B B16、grid108、TN64/TK64、R1 的 2、3、4、8 槽最大 CTA 历时分别为 72.704、62.464、63.488、62.464 µs。对应探针的 producer 发射与发布成本为 416.0、405.3、426.7、432.0 ns/K tile。grid216 的两个对应实例链接资源允许至少两 CTA/SM，且已用两倍 SM 数的 grid 执行。资源表单列 linked 容量、申请的 residency、local memory 和插桩开销。[Dense gate 服务与资源表](A800_SM80_R2_resources.csv)

**已验证。** MPK Llama-3.2-1B B4/B8/B16 的计时进程内输出可重复。同一 frozen checkpoint、prompt 下，独立 HF 在其完整轨迹上的最大 logit gap 分别为 0.078125、0.0625、0.0625。按现有容差接受已有计时，相应 TPOT 为 2.739、3.231、4.191 ms/token。这些轨迹与其他 baseline 的 greedy 首 token 存在近似并列，凭据保留各行的实际匹配结果。

**已测量。** `347288` 用相同 GEMM body 独立测量 producer 和 consumer，另一侧仍执行原 slot 的完整 arrivals。Llama-1B B16 的 108-CTA、2/3/8 槽 producer 发射分别为 368.0、304.0、373.3 ns/K tile，consumer MMA 均为 208.0 ns/K tile。`347284` 中，Llama-1B B1 的 U4 寄存器版和共享内存版对同一 U4 权重逐位一致。U4、U8、U16 的无插桩 stage 历时分别为 69.632、71.680、71.680 µs。这些是算子诊断数据。

**待验证。** Dense gate 价格使用精确的 body 哈希和几何 key，additive 与 CTG flow 共用实测服务来源，CPU 回归验证 HBM 字节数保持独立。现有数据尚未覆盖完整 startup/drain、MoE 路由交接及 grid216 的全部候选族。P3/P4 和新价格下的完整请求仍需保持正确性与时序验收。Llama-8B 的 copy issue 分组已完成独立验收，当前正式 TPOT 为 11.292 ms/token。
