This is an exploratory Llama decode B=16 solve restricted to the four-shape domain in `/root/r10_work/top1_shapes_domain.json`, one search pass and top-M=1. It is not a full-domain top-3 result or an EV-1 cell. Three fresh candidate-measurement processes used alternating mode order. The same byte-identical candidate binary was reused for the final plan; see `binary_reuse.txt`. `rounds.tsv` records per-round 32-step means, while `selected.tsv` records the median-of-rounds winner. `flow_parts.tsv` is the raw Level-1 price dump used to investigate the prediction gap. The external domain file and generated binary remain outside the repository.
