# A800 SM80 R3 R5 · service costs and replay

**Verified plan.** Verify MMA geometry prices with held-out keys. Compare the same published coordinates through the imported CTG and replay, alongside the new measured shortlist. Keep predictions distinct from timed requests. A difference between two matched measurements inside 0.50% is a tie. Keep unpriced work explicit and use measured, shape-matched local service where it exists.

**Verified model changes.** Dense producers use a local `cp.async` activation bound based on live rows, initial slot clearing and residual staging. It competes with transfer and MMA in the local bound. An exact dense service supersedes this bound. The model charges the actual last-wave task count and busiest owner. Register stages remain part of the linked resource and exact MMA key. The 141 matched stage-1/stage-2 geometry pairs have a median difference of −0.009%. Across those pairs, 45 differ by more than 0.50% in either direction, so the registry preserves each measured value. It supplies no universal scaling factor.

**Verified attention attribution.** The CTG carries QKV releases separately from each attention group's service. Attention follows the request distribution of past lengths and the one chunk that appends the new K/V row. A non-compact shape missing a direct append service has a positive scratch-and-cache write bound. Compact variants still require their measured append and synchronization price. The prior full-history replay measured differences below 0.008 ms across all five compared coordinates. [R2 request weighting and phase attribution](A800_SM80_R2.md)

**Verified held-out MMA cost.** The median relative error was 14.902% across 371 observations with a same-grid, same-TN, same-warp, same-register-stage neighbor. The current table keeps exact keys. This held-out arithmetic check does not measure end-to-end rank accuracy. [Coverage evidence](A800_SM80_R3_R1.md)

**Verified history repartition diagnosis.** Job `346142` changed the output hash when it changed eight logical attention chunks to thirteen. Each chunk performs a separate FP32 online accumulation and normalization before the final merge. Changing the partition changes both floating-point reduction boundaries. Job `351548_0` instead tested eight unchanged compute chunks plus five read-only L2 helpers per KV group. The helpers touch only history preceding the current row. Arithmetic, chunk ownership and synchronization stay on the original program. This retains the 1024 frozen output tokens. The experimental source is captured in each trial artifact under `runs/a800/optimization/r3-mandate/variants/attention-exact/`.

**Verified decision.** The exact-output helper difference was 0.029% and all three repeats were in the same direction. The signal falls inside the tie threshold. An independent thirteen-way floating-point reduction still changes the computation. The eight-chunk production coordinate remains selected.

**Verified concurrent intervals.** A CPU sweep merged each stage's active CTA intervals up to `t_tasks_end`, excluding time spent waiting for release. At B16, QKV and attention active work intersected in 0/512 Llama-8B layers (`350517`) and 0/768 Qwen30 layers (`350523`). Router and fused expert work intersected in 0/768 Qwen30 layers. The B1 archives had brief QKV/attention intersections in 58/512 Llama-8B and 12/768 Qwen30 layers, with a maximum of 1.024 µs (`346824`, `346938`) in the 16-position window. All four traces retained their reference outputs and had overhead below 2.12%. These CTA intervals support the isolated service treatment at B16. Per-interval HBM bytes remain unmeasured, so the CTG prices any overlapping load with the existing task-level contention model.
