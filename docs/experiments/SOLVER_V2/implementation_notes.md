# R9 implementation notes (measurements still running)

These are implementation and recovery facts, not completed gate conclusions.

- The GPU is available after the execution permission profile changed. The earlier missing-device observation is superseded; no R9 GPU gate is waived for it.
- The control uses the R8 deployed five-shape search domain and capacity 12, with the original six placement heuristics unchanged. The separate unrestricted Llama s4 audit did not finish and is not a timing result. Primary skeleton runs use the complete CandidateGenerator domain, every required split value, all estimated resident levels, and P=3.
- Only GEMM semantic classes have a discrete tile search. Scalar ownership remains the existing TaskBody ABI. This is the GEMM-only form allowed by §7.3; it is not a claim that every scalar geometry is searched.
- `SemanticSignature` retains indexing maps and exact `element_reads`; the cache is keyed by semantic producer/consumer identities, operand index and both granularities. Kernel resource compilation deduplicates identical template specializations across semantic classes and split values (split is a runtime field), while the solver maintains the specified semantic resource-cache entries.
- General Oracle fibers stay classified as General. After binding theta and the current coordinate, an additional `is_box` proof permits enumeration of that exact local box via per-dimension bounds. No unproved hull is substituted, no global adjacency is cached, and strided/disconnected fibers retain exact ISL point enumeration. The 337-case set-equality test includes a relation whose current fiber can be a box while the symbolic relation is General.
- The initial exact runtime relation audit exposed extra dependencies in the executor wait-window projection (1,280 extra edges in the diagnostic fixture). Search now composes physical ownership with the exact CG couplings. Runtime event/group dependencies are added only during final top-K materialization and legality checking; event semantics are unchanged.
- Three pre-existing frontend/analysis defects were repaired to permit the requested coverage, without touching TaskBodies: F32 RoPE frequencies were incorrectly counted as BF16 words; head-local unit reductions with parallel-coordinate offsets were rejected; Q/K projection and normalization emission assumed one particular valid FX ordering. The two Qwen export orderings now produce identical semantic buffer edges across 479 stages. These fixes are additional to the SV implementation; their diagnostic failures are retained under `admission/`.
- Model pattern matching caches reachability in the immutable export graph. A 19,680-comparison test checks it against independent traversal. Resident-level preparation caches are keyed by the entire CG text, target and theta; any mutation re-enters verification. Existing legality checks are unchanged.
- Candidate buffers are reused in the lazy EST scheduler. Spread is injective under the specified formula, so only the two affinity workers need duplicate checks. Worker choice still uses completion time, with explicit worker-number ties. The pre/post worker/slot/start/end digests and queue counters match on all three scheduler fixtures.
- Reference-model G-3 runs use a disclosed one-shape diagnostic domain and P=1, covering all splits and resident levels within that domain. They establish internal correctness, not full-domain search quality. The real-model G-8 matrix is separate and retains its full domain.
- Individual shortlisted candidates that fail compilation or internal equality are recorded and excluded. The selected arm must have ten valid fresh processes; a completely invalid shortlist fails the run. Existing reference configurations with internal inequality remain a global-stop condition.
- Complete legacy Llama measurement logs exist for seq 1, 4, 16, 64. They each contain ten fresh internally equal processes. Skeleton performance gates remain pending until the full matrix is available.
