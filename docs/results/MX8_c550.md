## AB4c：两种执行方式

**verified**：复用每格主实验选中几何、体、权重配方与 prefill。每个现有 MetaX stage 单独启动 kernel，取消跨 stage 预取；MoE 的每 CTA RouteTable 在 gate_up/down 间显式保存、恢复。
Graph 版捕获一个 decode step，由设备 cursor 推进；host-launch 版按同一顺序启动相同 stage kernels，不建立 Graph。内部归约仍属于各 stage body。
**inferred**：对主实验的差异同时包含 kernel 边界与局部性损失，不能解释为纯主机 launch 开销。

每版 **5 个正式新进程**检查 1024 token 的逐步/循环、跨进程、跨版本逐位一致；每版一次 HF teacher forcing，256 位置/序列。
主实验保留 token 的实际长度为 512 或 1024，按实际长度比较并在 CSV 记录；没有把 512 位置的主实验证据写成 1024。
正式计时为每版 **3 个新进程**，N1 与 N1024 各 warm1 + timed3，取进程中位数。

## C550 实测硬件基准

**verified**：8 张卡各运行 vector HBM、LDS HBM、BF16 MMA 三种 item，每种 item 5 个新进程，共 120 个进程、80 条配置汇总。
HBM 工作集为 8 GiB，配置取五进程中位数；效率归一化使用全卡所有有效配置中最大的中位数，不能取最快单次样本。
