Source-level checks are implemented in [verify.py](verify.py).

## Incomplete implementation and declared deviations

- **TF-1 `smem_direct`:** The specification requires a full `DirectHandoff<P,C>` CG-to-runtime path. Current code proves access and worker adjacency, rewrites the fused IR, provides a page helper, and passes a synthetic positive runtime-projection test. A reference-graph 1:1 edge with synthetic adjacent placement passes `VerifyHandoffAccess` and `ApplyHandoffs` (`HANDOFF_DIRECT two_stage_access=PASS ir_rewrite=PASS`); the separate 160-thread page helper test passed in the final ctest run. The lowering still does not emit a complete executable serving `smem_direct` handoff. There are zero eligible edges in the two real decode CGs, so the permitted fallback remains incomplete at codegen. The next step is to make this synthetic two-stage CG execute through generated serving code.
- **SV-18(d):** The specification requires a top-3 per-class measured-rate check and top-M rerank for deviations over 20%. The current class microbenchmarks compare paged against the old collective, but they do not estimate `measured/model` for every chosen class and do not rerank top-M. The down class shows a 1.90×/1.86× paged/old slowdown (Llama/Qwen3); integrate this rate observation into the candidate model and rerun ranking.
- **SV-18(g):** The specification allows equal neighboring B winners to share one interval plan. The current runtime binds one B per plan and `StructureInvariant` checks literal stage counts, so no cross-B interval plan is emitted. Implement a B-parameterized host queue and prove both endpoint windows before merging.
- **TF-2 scoring:** The specification prices each access-proved edge handoff in Level 1 and reruns top-M fluid simulation with those choices. The current handoff mask price is a stage-class approximation and top-M simulation remains on the event plan; final compiler timing tests an access-proved handoff binary and retains it only for a measured gain of at least 2%. A restricted Llama B1 case priced a handoff but selected no legal runtime edge, demonstrating this mismatch. See [handoff_closure](handoff_closure/README.md).
- **EV-2 scope:** The original 20-plan, ten-cell matrix is reduced by the user's explicit instruction to four plans and two Llama cells. All ten-cell gates remain unmeasured, not passed.

There is no legal edge of this kind in the two real decode CGs, so the specification's synthetic two-stage fallback must exercise the generated binary. SV-18(d) needs a measured/model class-rate ratio and a top-M reranking step; the current microbenchmark only compares paged and old collectives. SV-18(g) needs a B-parameterized host queue and endpoint proof before adjacent winners can share an interval plan; current manifests bind exactly one B. The narrowed B={1,16} acceptance has no adjacent B to exercise, but that does not make the implementation complete. The current C-2 failure blocks performance acceptance, not independent development of those paths.

For the C-2 failure, compare the normal and forced-all generated `TaskRef` waits, then audit `RuntimeDependencyBounds` and same-worker wait lifting in `ModelHarness.cuh:2660-2780`; the forced-all eight-step result is a diagnostic, not a production fallback or a 1,024-step pass. For the separate C-1 failure, compare B16 L1's first incorrect logits/activations against the HF reference at the first divergent rows before a full E2E rerun. For G-7, the B16 prefill 1,568.6 s plan points to the structure/pricing phase; the 400 s coordinate-scan limit alone cannot guarantee a 600 s end-to-end solve. A breakdown from its timing TSV should drive the next exact cache or candidate-domain change.

**Deviation register.** The user's narrowed scope replaces 20 plans/10 cells with four plans/two Llama cells; original G-9 remains unmeasured. The 400 s search cutoff can return a suboptimal candidate and did not ensure the total 600 s plan budget. TF-2 uses a stage-class handoff approximation and times the legal compiled binary, rather than exact per-edge Level 1 pricing followed by top-M fluid reranking. `smem_direct` and SV-18(d)/(g) remain incomplete as described above.
